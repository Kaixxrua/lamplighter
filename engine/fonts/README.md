# Fonts

All fonts are licensed under the SIL Open Font License 1.1 and come from Google Fonts; each family's
license, with its copyright line, is in OFL-<family>.txt (from github.com/google/fonts). The font files
ship with the published repository; in a checkout without them, download them again into this directory.

| File | Family | Use |
|---|---|---|
| NotoSerifSC-ExtraLight.otf / -Light.otf / -Regular.otf | Noto Serif SC | Chinese text, title cards (`FONTS.serif`) |
| EBGaramond-VF.ttf / EBGaramond-Italic-VF.ttf | EB Garamond | English serif, book text (`FONTS.garamond`) |
| JetBrainsMono-VF.ttf | JetBrains Mono | code pages, timecodes (`FONTS.mono`) |
| Anton-Regular.ttf | Anton | display type (`FONTS.display`) |
